# 常见问题

## 部署与费用

**CloudVault 是免费的吗？**

代码是 MIT，免费。运行成本由你的 Cloudflare 账号承担：Workers 请求、R2 存储和操作、KV 读写。用量小时通常在免费额度内，但不要把它当成“无限免费网盘”。

**必须要有域名吗？**

不必须。`*.workers.dev` 可以直接用。但自定义域名更适合长期分享，也方便给 `/admin` 加 Cloudflare Access。

**必须用 R2 吗？**

是。CloudVault 的存储层直接绑定 R2，没有 S3 兼容层的抽象。用别的对象存储需要改代码。

**可以部署多个实例吗？**

可以，但每个实例必须使用独立的 R2 桶和 KV 命名空间。共用会让文件、账号和分享混在一起。

## 使用

**支持多用户吗？**

支持账号和角色，但所有账号共享同一个文件库。它不是多租户网盘，没有“每个人一个独立空间”。

**有回收站吗？**

没有。删除是永久的。重要文件请自行备份。

**支持手机吗？**

页面是响应式的，手机浏览器可以上传、下载、预览和分享。没有原生 App，也没有 PWA 安装。

**支持英文吗？**

界面支持中英文切换。文档站目前以中文为主，英文 README 在仓库根目录。

**最大能传多大文件？**

应用层没有单独的总大小上限；限制来自 Cloudflare Workers 的请求体和 R2。前端对 10 MB 以上文件使用 16 MB 分片，避免单请求过大。具体额度见 [容量与限制](/config/limits)。

**能在线编辑 Office 文档吗？**

不能。Office 文件只能下载后用本地应用打开。WebDAV 也不支持文件锁，不适合多人同时编辑。

**能预览哪些格式？**

图片、视频、音频、PDF、Markdown、代码 / 纯文本。其他类型显示下载入口。

## 分享

**分享链接会被搜索引擎收录吗？**

没有 `robots` 层面的保证，但分享页需要随机 token，不会从首页链接出去。不要把 token 贴到公开页面。

**一个文件能生成多个分享链接吗？**

不能。一个文件只有一个 token；再次创建会更新密码和有效期，不会生成第二个。

**分享密码能改吗？**

能。重新创建分享并设置新密码即可，token 不变。

**删除文件后分享会怎样？**

分享记录会一起删除，链接失效。

**重命名文件后分享会失效吗？**

不会。分享记录会跟着新 key 更新，token 不变。

**访客页面和文件夹分享链接有什么区别？**

访客页面是站点首页的公开列表，受“访客共享”标记控制；文件夹分享链接是独立的 `/s/<token>` 入口，不需要把文件夹放到首页。

## WebDAV

**为什么 Windows 资源管理器连不上？**

常见原因是证书、Basic Auth 策略或 URL 末尾缺少 `/`。先用 rclone 验证账号和地址，再换客户端。

**为什么不能在线编辑？**

CloudVault 是 WebDAV Class 1，不实现 `LOCK` / `UNLOCK`。依赖文件锁的应用会失败。

**WebDAV 能看到访客分享吗？**

看不到。WebDAV 用账号登录，看到的是完整文件库，不受访客共享标记限制。

## 运维

**升级会丢数据吗？**

不会。升级只替换 Worker 代码，R2 和 KV 不动。但没有迁移脚本，也不要在升级时重建 KV。

**怎么备份？**

R2 用 S3 兼容工具同步，KV 用 Wrangler / API 导出。见 [备份与迁移](/config/backup)。

**忘记管理员密码怎么办？**

让另一个管理员重置；如果只剩一个管理员，需要从 KV 备份恢复或用 Cloudflare 侧工具处理。没有公开的找回入口。

**为什么改了设置没有立刻生效？**

KV 是最终一致的，公开首页还有 15–60 秒缓存。等一会儿或强刷。

## 与其他项目

**和 AList 有什么区别？**

AList 聚合多种网盘，重点是把别人的存储挂到一个界面里；CloudVault 是把自己的 R2 变成一个私有网盘，重点是自己掌控文件、分享和 WebDAV。两者目标不同，不是替代关系。

**可以从 AList 迁移吗？**

可以用 rclone 通过 WebDAV 把文件复制到 CloudVault，或直接从原存储复制到 R2。账号、分享记录不会自动迁移。

**为什么没有在线 Demo？**

项目文档和截图使用真实界面，但 Demo 地址由维护者单独提供。自部署是体验完整功能最可靠的方式。

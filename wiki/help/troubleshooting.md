# 故障排查

先定位“哪一层”出了问题：Cloudflare 路由、Worker、R2 / KV 绑定、账号会话、分享 token，还是客户端。

## 页面打不开

### 521 / 522 / 523

Cloudflare 无法连接到源站。CloudVault 没有传统源站，通常是路由没有指向 Worker：

- 检查 Worker 是否部署成功；
- 检查 Domains & Routes 是否 Active；
- 检查 DNS 记录是否被别的记录覆盖；
- 检查 `routes` / `custom_domain` 配置。

### 404

- 路径是否在 `run_worker_first` 里？`/`、`/admin`、`/api/*`、`/s/*`、`/login`、`/auth/*` 需要 Worker 先处理；
- 是否访问了不存在的页面；
- 静态资源是否在 `public/` 下。

### 500

先看日志：

```bash
wrangler tail
```

常见原因：

| 日志 | 原因 |
| --- | --- |
| `VAULT_BUCKET is not defined` | 绑定名写错或没部署 |
| `VAULT_KV is not defined` | KV 绑定缺失 |
| `nodejs_compat` 相关 | 缺少 compatibility flag |
| R2 权限错误 | Token / 桶名不对 |
| 未捕获异常 | 代码 bug，附请求路径提 issue |

## 初始化与登录

### `/setup` 一直跳 `/login`

说明 KV 里已经有账号。去 `/login`，不要重复初始化。

### 登录后立刻回到登录页

- 是否 HTTPS？`Secure` Cookie 在 HTTP 下可能写不进去；
- 域名是否和 Cookie 的 Domain 一致；
- 是否在反向代理后丢了 `Set-Cookie`；
- 浏览器是否禁用了 Cookie；
- Cloudflare Access 是否又把人踢回登录页。

### 401

会话过期（7 天）或被撤销。重新登录。管理员重置密码会撤销该账号所有会话。

### 429

触发限流。登录 5 次 / 10 分钟，WebDAV 20 次 / 10 分钟，分享密码 8 次 / 10 分钟。等窗口结束，或检查是否有客户端在疯狂重试。

## 上传

### 413

- 文件超过 Cloudflare 请求体限制；
- 或者你用的是直传路径，但文件大于 10 MB，前端本应切到分片；
- 检查反向代理 / WAF 是否也有请求体限制。

### 分片上传失败

- 网络中断；
- R2 分片超时；
- `uploadId` 丢失；
- 页面刷新导致无法续传。

未完成的分片会留在 R2，等生命周期规则清理；不会出现在文件列表。

### 文件名报错

文件名不能包含 `/`、`\`、控制字符，不能是 `.` / `..`，不能叫 `.cv-folder`，最长 255 字符。

## 下载与 ZIP

### ZIP 413

单次最多 200 个文件、512 MB。减少选择范围，或改用 WebDAV / rclone。

### 下载中断

- 大文件建议用支持断点续传的客户端；
- 浏览器下载受网络影响；
- 检查 Range 是否被中间代理破坏。

## 分享

### `/s/<token>` 404

- token 是否正确、完整；
- 是否已撤销；
- 是否已过期；
- 文件是否已删除；
- 分享记录是否在 KV 里（从备份恢复时容易漏）。

### 密码输入后仍然回到密码页

- Cookie 没写进去：检查 HTTPS、`Path=/s/<token>`、浏览器 Cookie 设置；
- 分享密码错误；
- 代理改写了路径；
- 分享已被撤销。

### 访客首页没有内容

- **启用访客页面** 是否打开；
- 文件夹是否标记为访客共享；
- 是否被祖先的排除标记挡住；
- 分享是否过期；
- 等 15–60 秒缓存。

### 公开简洁地址 404

文件必须位于访客共享文件夹内。根目录文件、私有目录文件不会通过 `/<folder>/<file>` 暴露。

## WebDAV

| 状态 | 排查 |
| --- | --- |
| 401 | 账号密码、Basic Auth、Access 拦截 |
| 403 `propfind-finite-depth` | 递归超过 5000，改用 Depth: 1 或 rclone |
| 405 | 对集合 `PUT`，或对根 `MKCOL` |
| 409 | 父目录不存在，或复制到自身 |
| 412 | `If-Match` / `If-None-Match` 失败，或 `Overwrite: F` |
| 501 | `LOCK` / `UNLOCK` / `PROPPATCH` 未实现 |

Windows / Finder 连接失败时，先用 rclone 排除账号和路径问题。

## 设置与缓存

### 改了站点名称没变

- 刷新页面；
- KV 最终一致，等几秒；
- 公开首页有 15 秒浏览器缓存 / 60 秒边缘缓存。

### 自定义图标不显示

- 必须是 `http://` 或 `https://`；
- 图片必须可公开访问；
- 不要用需要登录的地址；
- 检查浏览器是否拦截混合内容。

## 数据

### 文件在 R2 控制台有，页面看不到

- 确认桶和绑定是同一个；
- 点击 **同步 R2** 刷新统计；
- 检查对象 key 是否在根目录之外；
- 检查是否被 `.cv-folder` 或过滤规则影响。

### 账号 / 分享突然都没了

高度怀疑 KV 被删除或换了命名空间。先停止写入，检查绑定和 KV 列表，再从备份恢复。不要继续在空 KV 上创建新账号，否则会覆盖恢复目标。

## 还是解决不了

开 issue 时附上：

- 访问路径和 method；
- HTTP 状态；
- `wrangler tail` 的相关日志；
- 是否使用自定义域名 / Access；
- 复现步骤。

不要附真实 token、密码、Cookie 或私密文件内容。

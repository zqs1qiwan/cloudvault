# CloudVault 是什么

CloudVault 是一个跑在 **Cloudflare Workers + R2** 上的开源私有云盘。它把应用逻辑放在 Worker 里，把文件本体放在 R2 里，把账号、站点设置和分享签名密钥放在 KV 里。

它面向的是这样的情况：

- 你已经有 Cloudflare 账号，想把手头的文件放到自己的存储里；
- 你不想为一个小型文件库买 VPS、装数据库、维护反向代理；
- 你需要网页管理、分享链接、访客浏览和 WebDAV，而不是一整套在线办公套件；
- 你希望代码可读、可改、可自己部署，而不是只能用某个托管服务。

## 它做什么

| 能力 | 说明 |
| --- | --- |
| 文件与文件夹 | 上传、下载、重命名、移动、删除、批量 ZIP 下载 |
| 在线预览 | 图片、视频、音频、PDF、Markdown 和常见代码文件 |
| 分享链接 | 单文件密码保护、有效期、下载次数 |
| 访客页面 | 未登录浏览共享文件夹和公开文件 |
| 文件夹链接 | 给整个文件夹生成独立链接，支持密码和有效期 |
| WebDAV | 挂载为网络硬盘，支持文件与文件夹的移动、复制 |
| 账号与权限 | 管理员 / 普通用户，管理员管理成员与站点设置 |
| 双语双主题 | 中文 / English，深色 / 浅色 |
| 一键部署 | Deploy to Cloudflare，自动创建 R2 与 KV |

## 它不做什么

CloudVault 有意保持单租户、轻量：

- 没有公开注册，也没有多租户隔离；所有账号共享一个文件库。
- 没有在线文档协作、评论、版本历史或回收站；删除是永久的。
- 不是 Nextcloud 的完整替代品：没有日历、联系人、聊天、协作编辑。
- 不提供托管服务；你需要自己的 Cloudflare 账号和 R2 计费。
- 不把 R2 桶直接公开到公网，文件通过 Worker 鉴权后读取。

## 架构一眼看懂

```text
浏览器 / WebDAV 客户端
        │
        ▼
Cloudflare Worker
  ├─ 页面与登录（/、/login、/admin、/setup）
  ├─ 私有 API（/api/*）
  ├─ 公开分享（/s/*、/api/public/*）
  ├─ WebDAV（/dav/*）
  └─ 静态资源（public/）
        │
        ├──────────────► R2：文件本体
        └──────────────► KV：账号、会话、分享记录、站点设置
```

Worker 是唯一的应用入口。R2 只存文件；KV 只存控制面数据。没有额外的数据库，也没有一份会和 R2 字节不一致的索引。

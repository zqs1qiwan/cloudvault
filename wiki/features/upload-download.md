# 上传与下载

## 上传

### 拖拽

把文件拖进窗口即可上传到当前目录。浏览器支持目录拖入时，CloudVault 会递归读取目录结构并在目标位置创建对应文件夹。

### 按钮上传

点击 **上传** 选择文件。上传队列会显示每个文件的状态和进度。

### 小文件与大文件

前端按文件大小选择不同路径：

| 文件大小 | 上传方式 |
| --- | --- |
| 小于 10 MB | 直接 `POST /api/files/upload`，一次请求发送整个文件 |
| 10 MB 及以上 | R2 分片上传：创建 uploadId，按 16 MB 分片，完成后合并 |

分片上传的细节：

- 同时最多 3 个文件在上传；
- 单个文件最多 3 个分片并发；
- 每个分片失败会重试，最多 3 次；
- 页面关闭时会尝试中止未完成的分片会话，避免留下悬空上传。

> 刷新页面不会“续传”未完成的上传。刷新后需要重新选择文件。R2 未完成的分片会由 R2 的生命周期规则清理。

### 文件名与路径

- 文件名不能包含 `\`、`/` 或控制字符；
- 文件名不能是 `.` / `..`；
- 文件名最长 255 个字符；
- `.cv-folder` 是内部保留名，不能作为用户文件名；
- 目标文件夹必须已经存在，或由目录拖拽自动创建。

### 同名文件

上传同名文件会覆盖 R2 中的同键对象，并产生新的 ETag。旧分享 token 仍然指向同一个键，因此分享不会断，但内容变成新文件。

### 上传失败

| 现象 | 可能原因 |
| --- | --- |
| 401 | 会话过期，重新登录 |
| 413 / 请求体过大 | 文件超过当前 Cloudflare 计划的请求限制 |
| 分片失败 | 网络中断、R2 分片超时，重试或换网络 |
| 页面关闭后残留 | 分片中止请求可能失败，等待 R2 生命周期清理 |
| 文件名报错 | 包含非法字符或保留名 |

Cloudflare Workers 的请求体、CPU 时间和 R2 操作额度都会影响上传。具体额度见 [容量与限制](/config/limits)。

## 下载

### 单文件

点击文件菜单里的 **下载**，或直接访问：

```text
/api/files/download?key=<url-encoded-key>
```

响应使用 `Content-Disposition: attachment`，并支持：

- `Range` 请求，视频拖动进度条不会整文件重读；
- `ETag` / `If-None-Match` 的 304；
- `Last-Modified` / `If-Modified-Since`；
- `If-Match` 的条件写入保护（主要给 WebDAV 客户端）。

### 批量 ZIP

选中多个文件后点击打包下载。限制是：

| 限制 | 值 |
| --- | --- |
| 单次最多文件数 | 200 |
| 解压前总大小 | 512 MB |

ZIP 是流式生成的，不会先在 Worker 内存里拼完整包。超过限制会返回 413，并提示减少文件数量。

> ZIP 只打包选中的**文件**，不会把子文件夹递归打包。需要整个目录时，请在文件管理器里逐层选择，或使用 WebDAV / rclone 同步。

### 分享下载

公开分享页的下载走：

```text
/s/<token>/download
```

只有 token 有效、密码校验通过、文件仍存在时才返回字节。下载成功会异步增加该分享的下载计数。

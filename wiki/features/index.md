# 功能总览

CloudVault 的功能围绕三个场景组织：**管理自己的文件**、**把选定内容分享出去**、**用熟悉的客户端访问同一个文件库**。

## 管理文件

- 拖拽上传文件，也可以拖入整个目录；
- 网格和列表两种视图，按图片、视频、音频、文档、压缩包、代码筛选；
- 多级文件夹、重命名、移动、删除、批量 ZIP；
- 图片灯箱、视频 / 音频播放、PDF、Markdown、代码预览；
- 仪表盘显示文件数、总大小、最近上传和下载排行。

## 分享出去

- 单文件分享链接：密码可选，有效期可选，记录下载次数；
- 文件夹分享链接：整个文件夹一个 token，可设密码和有效期；
- 访客页面：把某个文件夹标记为“访客可见”，未登录首页直接浏览；
- 子目录排除：共享一个文件夹，但把其中一个子目录藏起来；
- 简洁地址：公开文件夹中的文件可以通过 `/<folder>/<file>` 直接访问。

## 用客户端访问

- WebDAV：挂载到 Finder、Windows 资源管理器、rclone、Cyberduck；
- WebDAV 使用账号密码，和网页登录同一套凭据；
- 支持 `PROPFIND`、`GET`、`HEAD`、`PUT`、`DELETE`、`MKCOL`、`MOVE`、`COPY`；
- 不支持 `LOCK` / `UNLOCK`，所以是 WebDAV Class 1。

## 管理站点

- 管理员可以改站点名称、图标 URL、是否启用访客页面、是否显示登录按钮；
- 添加成员，设置 `admin` / `user` 角色，重置密码；
- 最后一个管理员不能被删除或降级；
- 所有账号共享同一个文件库，没有公开注册。

# 文件与文件夹

登录后进入 `/admin`。左侧是文件夹树，右侧是当前目录的文件网格或列表。

## 界面结构

| 区域 | 用途 |
| --- | --- |
| 文件夹树 | 在目录之间跳转，显示层级关系 |
| 文件网格 / 列表 | 当前目录的文件和子文件夹 |
| 搜索框 | 在当前目录内按文件名搜索 |
| 类型筛选 | 图片、视频、音频、文档、压缩包、代码、其他 |
| 统计区 | 文件总数、总大小、最近上传、下载排行 |
| 上传 / 新建文件夹 | 当前目录的新内容入口 |
| 右键菜单 | 分享、重命名、移动、删除、下载 |

## 文件夹

文件夹不是数据库里的记录，而是 R2 对象键的路径前缀：

```text
root/                 根目录（空键前缀）
Projects/             一级文件夹
Projects/2026/        二级文件夹
Projects/2026/a.pdf   文件键 = Projects/2026/a.pdf
```

因此文件夹在第一次有内容时就“存在”。**空文件夹**需要一个占位对象，CloudVault 用 `.cv-folder` 作为标记。这个标记不会出现在文件列表里。

### 新建

1. 点击 **新建文件夹**；
2. 输入名称，选择当前父目录；
3. 名称不能包含 `/`、`\` 或控制字符；不能是 `.` / `..`；最长 255 个字符。

### 重命名

重命名会移动整个子树，然后同步重定向：

- 子树里的每个对象键；
- 指向这些文件的分享 token；
- 文件夹级分享标记；
- 文件夹分享链接。

这是一个“先复制、再删除”的过程，不是原子事务。中途失败时可能留下部分结果，但不会让旧目录和新目录同时“看起来都正确”。

### 删除

删除文件夹会递归删除其下所有对象，并清理：

- 文件分享记录；
- 文件夹分享标记；
- 文件夹分享链接。

**删除是永久的，没有回收站。** 重要文件请先下载或在 R2 侧做备份。

## 文件操作

| 操作 | 行为 |
| --- | --- |
| 下载 | 以附件形式返回原文件，支持 Range |
| 重命名 | 保持 `uploadedAt`，并重定向已有分享 |
| 移动 | 移动到目标文件夹；同名冲突会整体拒绝 |
| 删除 | 单个或批量；永久删除并撤销对应分享 |
| 打包下载 | 多个文件生成流式 ZIP |
| 分享 | 生成或更新该文件的分享 token |

## 搜索与筛选

搜索是**当前目录内**的文件名包含匹配，不递归子目录。类型筛选由前端按 MIME 和扩展名分组：

- Images：`image/*`
- Videos：`video/*`
- Audio：`audio/*`
- Documents：PDF、Office、文本等
- Archives：zip / tar / gz / rar / 7z 等
- Code：源码和配置文件
- Other：其余类型

## 空状态

- 根目录没有文件：显示“拖拽文件到此处，或点击上传开始”；
- 子目录为空：显示“此文件夹为空”；
- 搜索无结果：显示匹配提示。

## 数据一致性

文件列表直接读 R2 的 `list()`，单个文件直接 `head()`。没有单独的文件索引，因此：

- 重命名 / 移动后不会出现“R2 有文件但列表没有”；
- 删除后不会残留幽灵记录；
- 总数和文件夹树有一份 30 秒的统计快照，只用于计数和树展示，不影响真实文件读取。

如果你直接在 Cloudflare 控制台往 R2 放了对象，仪表盘的 **同步 R2** 可以刷新统计和文件夹视图。它不会重建文件本体，也不会修改对象。

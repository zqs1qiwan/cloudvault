# 成员与权限

CloudVault 是单租户应用：所有账号共享同一个文件库。账号系统解决的是“谁能进来、谁能管理站点”，不是“每个人一个独立空间”。

## 角色

| 能力 | `admin` | `user` |
| --- | --- | --- |
| 文件上传 / 下载 / 移动 / 删除 | 是 | 是 |
| 创建文件分享 | 是 | 是 |
| 文件夹访客共享 / 排除 | 是 | 是 |
| WebDAV | 是 | 是 |
| 修改站点设置 | 是 | 否 |
| 查看 / 添加 / 修改 / 删除成员 | 是 | 否 |
| 修改自己的密码 | 是 | 是 |

普通用户调用管理接口会得到 `403 Administrator role required`。

## 添加成员

管理员进入 **用户 → 添加用户**，填写：

- 用户名：3–32 个字符，字母、数字、点、短横线、下划线；必须以字母或数字开头和结尾；
- 密码：至少 8 个字符；
- 角色：`admin` / `user`。

创建成功后，成员可以立即用这组凭据登录网页和 WebDAV。

## 修改成员

管理员可以：

- 改用户名；
- 改角色；
- 重置密码。

重置密码会：

1. 更新该账号的密码哈希；
2. 标记 `mustChangePassword`；
3. 撤销该账号的所有现有会话。

对方重新登录后会被要求设置新密码。管理员重置密码不会影响 R2 里的文件，也不会删除该账号的分享。

## 删除成员

- 不能删除当前登录的账号；
- 不能删除或降级最后一个管理员；
- 删除会同时撤销该账号的会话和用户名索引。

删除账号不会删除文件。文件属于整个共享文件库，不属于某个成员。

## 修改自己的密码

在账号菜单选择 **修改密码**：

1. 输入当前密码；
2. 输入新密码；
3. 当前设备保持登录，其他设备的会话被撤销。

当前密码错误返回 `403`，不会修改任何东西。

## 最后一个管理员

系统会在两个地方阻止“把唯一管理员弄没”：

- 删除管理员时，如果只剩一个，返回 `409`；
- 把管理员降级为 `user` 时，如果只剩一个，返回 `409`。

这是为了避免一个实例变成“有文件、有账号，但没人能管理”。

## 账号边界

- 没有公开注册；
- 没有邮箱验证、短信、2FA；
- 没有按用户隔离的文件库；
- 没有审计日志导出；
- 会话 7 天有效，退出登录只删除当前会话。

需要更强的访问控制时，把整个站点或 `/admin` 放到 Cloudflare Access 后面，见 [Cloudflare Access](/security/access)。

## 常见问题

**两个用户能同时改同一个文件吗？**

网页端没有协作锁。同名上传会覆盖对象；WebDAV 客户端可以用 `If-Match` 做条件写入，但这不是完整的协作编辑。

**删除用户会删掉他的分享吗？**

不会。分享属于文件，不属于创建者。分享 token 继续有效，直到被撤销、文件被删除或过期。

**普通用户能看到其他用户的账号吗？**

不能。`GET /api/users` 只对管理员开放。

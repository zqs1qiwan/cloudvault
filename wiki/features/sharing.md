# 分享链接

CloudVault 有两类分享：**单文件分享**和**文件夹分享链接**。它们都不需要对方注册账号。

## 单文件分享

### 创建一个链接

1. 在文件上右键，选择 **分享**；
2. 在 **分享文件** 弹窗里设置密码（可选）和有效期（天）；
3. 点击 **创建链接**；
4. 复制 `/s/<token>` 地址。

有效期填 `0` 表示永不过期；允许的最大有效期是 **3650 天**。密码留空表示无密码。

### 一个文件只有一个 token

分享记录以 token 为键，指向一个 R2 对象键。对同一个文件再次创建分享时：

- 如果已有记录，会复用原 token；
- 新密码和有效期会覆盖旧设置；
- 下载计数保留。

这样做的好处是：撤销时不需要记一堆链接，一个文件的分享只有一个入口。

### 链接长什么样

| 地址 | 用途 |
| --- | --- |
| `/s/<token>` | 分享页；有密码时先显示密码输入 |
| `/s/<token>/download` | 直接下载，附件形式 |
| `/s/<token>/preview` | 内联预览，图片 / 视频 / PDF 等 |
| `/s/<token>/verify` | POST 密码校验，成功后写入 1 小时访问 Cookie |

token 由 18 个随机字节生成，base64url 编码。它不包含文件路径，也不可猜测。

### 撤销

在文件菜单点击 **撤销链接**，或调用：

```http
DELETE /api/share/<url-encoded-key>
```

撤销会删除 KV 里的分享记录。之后 `/s/<token>` 返回“链接已过期或撤销”。

### 文件被重命名或移动后

分享不会断。CloudVault 在重命名 / 移动文件时会把分享记录里的 `key` 改成新键，token 保持不变。

如果文件被删除，对应分享记录也会被删除。

## 文件夹分享链接

文件夹链接适合把一整个目录交给外部的人浏览，而不是逐个文件分享。

1. 在文件夹上右键，选择 **分享文件夹链接**；
2. 设置密码和有效期；
3. 生成 `/s/<token>`，打开后是一个可浏览的文件夹页面。

规则：

- 根目录不能生成文件夹链接；
- 一个文件夹只有一个链接；再次创建会更新密码和有效期；
- 链接只能访问该文件夹及其子目录；
- 子目录里被 **从分享中排除** 的文件夹仍然不可见；
- 文件夹重命名 / 移动时，链接会自动重定向到新路径；
- 删除文件夹会同时撤销其链接。

文件夹链接不会自动出现在公开首页；它是独立的、按 token 访问的入口。

## 密码保护

分享密码使用和账号密码相同的 PBKDF2 记录格式。密码校验成功后：

- 写入 `share_auth_<token>` Cookie；
- Cookie 是 HMAC 签名值，不是密码；
- `HttpOnly`、`Secure`、`SameSite=Lax`；
- `Path=/s/<token>`，只对这个分享生效；
- 有效期 1 小时。

密码错误会按“token + IP”限流，10 分钟内最多 8 次失败尝试。

> 分享密码不是账号密码。对方只需要分享密码，不需要 CloudVault 账号。

## 下载计数

分享页会显示下载次数。计数在下载响应发出后异步增加，因此：

- 失败或 304 响应不会增加；
- 并发下载可能少计一次，但不会让下载失败；
- 计数不是计费依据，只是展示。

## 公开可见性

单文件分享默认是一个独立链接，不会自动让文件出现在公开首页。只有以下情况，未登录访客才会在首页看到文件：

- 文件在一个被标记为 **访客可见** 的文件夹里；或
- 该文件本身有一条公开分享记录。

具体规则见 [访客页面](/features/guest)。

## 分享前检查

- 密码是否足够强？分享密码没有找回入口。
- 有效期是否必要？临时交付尽量设置 7 / 30 天。
- 文件是否包含隐私信息？预览和下载都会拿到原始字节。
- 是否需要限制访问范围？文件夹链接比“把整个目录设成公开”更可控。

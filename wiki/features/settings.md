# 站点设置

管理员在 `/admin` 的 **设置** 面板里管理站点外观与公开状态。设置保存在 KV 的 `settings:site`。

## 可配置项

| 设置 | 作用 | 范围 |
| --- | --- | --- |
| 站点名称 | 页头、页面标题、公开页显示的名字 | 最长 50 个字符 |
| 图标地址 | 自定义 Logo / favicon 的 URL | 只接受 `http://` / `https://`，最长 500 字符 |
| 启用访客页面 | 未登录访问 `/` 时是否显示公开内容 | 布尔值 |
| 显示登录按钮 | 访客页是否显示“管理员”入口 | 布尔值 |

没有“上传 Logo 文件”的内置功能。图标使用外部 URL，CloudVault 只把它写进页面的 favicon 和品牌数据。

## 站点名称

- 为空时回退为 `CloudVault`；
- 会出现在浏览器标题、页头品牌和访客页；
- 不解析 HTML，按文本注入。

修改后，已打开的页面需要刷新才能看到新名称。

## 图标地址

填一个可公开访问的图片 URL，建议：

- 正方形 PNG / SVG；
- 至少 64×64；
- 使用 HTTPS；
- 不要依赖需要登录的地址，否则浏览器拿不到图。

只接受 `http:` / `https:` 协议。`javascript:`、`data:` 等会被丢弃，空值会回到默认云图标。

## 访客页面

打开后：

- 未登录访问 `/` 显示共享文件夹和公开文件；
- 已登录访问 `/` 也显示访客页，可从页头进入 `/admin`；
- 公开内容仍受文件夹分享和排除规则约束。

关闭后：

- 未登录访问 `/` 跳 `/login`；
- 已登录访问 `/` 跳 `/admin`；
- 已有的文件夹链接和单文件分享链接仍然有效。

访客页面不是“把整个网盘公开”。没有共享的文件夹和文件不会出现。

## 显示登录按钮

访客页右上角默认显示 **管理员** 按钮，方便所有者登录。对外分享的站点可以关闭它，让页面更像一个纯公开文件页。

登录按钮关闭后，仍然可以直接访问 `/login`。

## 设置何时生效

设置写入 KV 后立即返回。由于 KV 是最终一致的：

- 当前边缘节点通常马上生效；
- 其他地区可能有几秒到几十秒延迟；
- 公开首页有 15 秒浏览器缓存 / 60 秒边缘缓存，切换后可能短暂看到旧内容。

## 没有暴露的设置

以下内容不在 UI 里改，需要改代码或绑定：

- R2 桶名 / KV 命名空间；
- 会话长度、限流阈值；
- 上传分片大小；
- ZIP 限制；
- 自定义 CSS / 页面结构。

这些属于部署配置，见 [绑定与配置](/config/bindings)。

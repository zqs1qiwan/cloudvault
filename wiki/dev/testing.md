# 测试

CloudVault 的测试目标是“路由和领域逻辑在真实请求形态下可重复”，不是追求覆盖率数字。

## 运行

```bash
npm test            # vitest run
npm run typecheck   # tsc --noEmit
npm run check       # 两者都跑
```

提交前至少跑一次 `npm run check`。CI 也使用这个命令。

## 测试分层

| 层 | 关注点 |
| --- | --- |
| 路由 | 路径匹配、method、公开 / 私有边界、404 |
| 认证 | 初始化、登录、会话、退出、角色 |
| 文件 | 列表、元数据、上传、重命名、移动、删除、ZIP 限制 |
| 分享 | 创建、复用 token、撤销、过期、密码、文件夹链接 |
| 访客 | 共享标记、排除标记、祖先继承、公开路径 |
| WebDAV | OPTIONS、PROPFIND、PUT、MOVE、COPY、Depth 上限 |
| 安全 | 响应头、限流、路径校验、预览沙箱 |
| HTML | `public/*.html` 的基本结构和关键元素 |

## 测试环境

测试使用 Vitest，配合 Node 环境和模拟的 R2 / KV 绑定。它不启动真实 Worker，也不访问线上 R2。

这意味着：

- 测试能覆盖业务逻辑和路由分发；
- 不能完全覆盖 Cloudflare 边缘行为、真实 R2 分片、KV 最终一致性；
- 上传分片、Range、WebDAV 的真实兼容性仍需要手工验证。

## 手工验收清单

发布前建议在本地或预览实例上走一遍：

- [ ] `/setup` 创建管理员；
- [ ] 退出后 `/login` 能登录；
- [ ] 上传小文件（< 10 MB）和大文件（> 10 MB）；
- [ ] 新建文件夹、重命名、移动、删除；
- [ ] 图片 / 视频 / PDF / Markdown 预览；
- [ ] 创建带密码的分享，无痕窗口验证密码；
- [ ] 撤销分享后链接失效；
- [ ] 文件夹访客共享，公开首页可见；
- [ ] 排除子目录后公开首页不可见；
- [ ] WebDAV `PROPFIND` / `PUT` / `MOVE`；
- [ ] 普通用户无法访问 `/api/users`；
- [ ] 最后一个管理员不能被删除；
- [ ] 移动端布局和深色主题。

## 写测试的约定

- 一个行为一个断言重点，不要把所有东西塞进一个用例；
- 用真实的 key / 文件夹路径，不要只测空字符串；
- 覆盖失败路径：401、403、404、409、413；
- 分享测试要覆盖“过期”和“撤销”，不只测成功；
- 文件测试要覆盖重命名后分享是否重定向；
- 安全测试要覆盖 `..`、编码后的 `..`、反斜杠。

## 不测的东西

- 第三方 UI 库的内部行为；
- Cloudflare 自身的 SLA；
- 真实浏览器渲染像素级差异；
- 真实 R2 的计费。

这些要么无法在单测里稳定复现，要么属于外部系统。
